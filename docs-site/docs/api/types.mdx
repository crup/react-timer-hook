# Types

## Duration parts

```ts
type DurationParts = {
  totalMilliseconds: number;
  totalSeconds: number;
  milliseconds: number;
  seconds: number;
  minutes: number;
  hours: number;
  days: number;
};
```

```ts
import { durationParts } from '@crup/react-timer-hook';

const parts = durationParts(90_500);
```

## Schedules

```ts
type TimerScheduleContext = {
  scheduleId: string;
  scheduledAt: number;
  firedAt: number;
  nextRunAt: number;
  overdueCount: number;
  effectiveEveryMs: number;
};

type TimerSchedule = {
  id?: string;
  everyMs: number;
  leading?: boolean;
  overlap?: 'skip' | 'allow';
  callback: (
    snapshot: TimerSnapshot,
    controls: TimerControls,
    context: TimerScheduleContext,
  ) => void | Promise<void>;
};
```

`scheduledAt` is the intended fire time. `firedAt` is when the browser actually ran the callback. `overdueCount` reports how many schedule windows were missed before this callback because the browser, tab, or previous work delayed execution.

## Debug

Debug is opt-in. The package does not emit logs by default.

```ts
type TimerDebug =
  | boolean
  | TimerDebugLogger
  | {
      enabled?: boolean;
      logger?: TimerDebugLogger;
      includeTicks?: boolean;
      label?: string;
    };
```
