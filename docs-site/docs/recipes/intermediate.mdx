# Intermediate recipes

## 6. Call an action once on end

<RecipePlayground title="Once-only onEnd">
  <OnEndSample />
</RecipePlayground>

```tsx
useTimer({
  autoStart: true,
  endWhen: snapshot => snapshot.elapsedMilliseconds >= 5000,
  onEnd: () => api.markDone(),
});
```

## 8. Poll and cancel early

<RecipePlayground title="Poll and cancel">
  <PollAndCancelSample />
</RecipePlayground>

```tsx
callback: async (_snapshot, controls) => {
  const auction = await api.getAuction(auctionId);
  if (auction.status === 'sold') controls.cancel('sold');
}
```

## 9. React to a backend event

<RecipePlayground title="Backend event stop">
  <BackendEventSample />
</RecipePlayground>

```tsx
useEffect(() => {
  return subscribeToAuction(auctionId, event => {
    if (event.type === 'auction:sold') timer.cancel('sold');
  });
}, [auctionId, timer.cancel]);
```
