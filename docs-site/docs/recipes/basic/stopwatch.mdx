# Stopwatch

Use `elapsedMilliseconds` for active elapsed time. It is independent from clock formatting.

```tsx
const timer = useTimer({ updateIntervalMs: 100 });
const seconds = Math.floor(timer.elapsedMilliseconds / 1000);
```
