# Basic recipes

## 1. Wall-clock display

<RecipePlayground title="Wall-clock display">
  <WallClockSample />
</RecipePlayground>

Use `timer.now` and format it in userland.

```tsx
const timer = useTimer({ autoStart: true, updateIntervalMs: 1000 });
return <time>{new Date(timer.now).toLocaleTimeString()}</time>;
```

## 2. Stopwatch

<RecipePlayground title="Stopwatch">
  <StopwatchSample />
</RecipePlayground>

```tsx
const timer = useTimer({ updateIntervalMs: 100 });
return <output>{Math.floor(timer.elapsedMilliseconds / 1000)}s</output>;
```

## 3. Absolute deadline countdown

<RecipePlayground title="Absolute deadline countdown">
  <AbsoluteCountdownSample />
</RecipePlayground>

```tsx
const timer = useTimer({
  autoStart: true,
  endWhen: snapshot => snapshot.now >= expiresAt,
});

const remainingMs = Math.max(0, expiresAt - timer.now);
```

## 4. Pausable duration countdown

<RecipePlayground title="Pausable duration countdown">
  <PausableCountdownSample />
</RecipePlayground>

```tsx
const timer = useTimer({
  autoStart: true,
  endWhen: snapshot => snapshot.elapsedMilliseconds >= durationMs,
});
```
