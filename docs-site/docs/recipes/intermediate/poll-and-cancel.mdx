# Poll and cancel

Use `cancel(reason)` for terminal early stops that should not call `onEnd`.

```tsx
callback: async (_snapshot, controls) => {
  const auction = await api.getAuction(auctionId);
  if (auction.status === 'sold') controls.cancel('sold');
}
```
