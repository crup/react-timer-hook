# Once-only onEnd

`onEnd` fires once per generation. `restart()` creates a new generation and allows it to fire again.

<RecipePlayground title="Once-only onEnd">
  <OnEndSample />
</RecipePlayground>

```tsx
useTimer({
  autoStart: true,
  endWhen: snapshot => snapshot.elapsedMilliseconds >= 5000,
  onEnd: () => api.markDone(),
});
```
