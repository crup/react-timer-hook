# Polling schedule

Schedules run while the timer is active. Async overlap defaults to `skip`.

  <PollingSample />
</RecipePlayground>

```tsx
useTimer({
  autoStart: true,
  schedules: [{ id: 'refresh-status', everyMs: 5000, callback: refresh }],
});
```
